# Prototypes

This directory contains functioning prototype work that predates the canonical [`experiments/`](../experiments/) workshop launcher.

Use [`experiments/README.md`](../experiments/README.md) to find and run executable experiments.

Working prototypes stay here while their paths are already in use; moving them only to normalize the tree would create churn without improving the experiment. New executable implementations should normally start under `experiments/<slug>/`.
