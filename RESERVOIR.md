# Tact reservoir

**A low-friction place to keep things worth seeing again.**

This is not a taxonomy project. The reservoir exists so references can enter Tact before anybody knows exactly what category they belong to.

The default capture rule is:

> **Drop it in. Say what caught the eye. Leave classification for later.**

A reference can be:

- a screenshot;
- a screen recording;
- a product or page link;
- a code/component link;
- a game UI;
- a physical object;
- an industrial design detail;
- architecture or wayfinding;
- typography;
- motion;
- a diagram;
- an interaction sequence;
- a weird thing that is difficult to categorize but clearly worth remembering.

## Minimal capture format

One line can be enough:

```text
<source / artifact>
What caught me: <the exact thing worth returning to>
```

A better capture, when the thought is available:

```text
Source:
What caught me:
What it seems to solve:
What I might steal:
Where it might transfer:
Caveat / why literal copying would fail:
```

Do not require every field.

## What “worth stealing” means

Avoid entries like:

> Linear looks clean.

Prefer:

> The selected row stays visually obvious with a very small state delta because surrounding rows are quiet and share strict alignment. Worth comparing against selection treatments that spend fill + border + accent + brighter text simultaneously.

Avoid:

> This car interior is beautiful.

Prefer:

> The physical controls cluster around the hand's resting position, while infrequent configuration moves to the screen. The separation appears to follow frequency and eyes-off operation rather than feature category.

The point is to preserve the **mechanism that triggered the reaction**.

## Inbox

Add loose references here or as nearby files. Do not create a new folder merely because one item arrived.

When several references clearly belong together, split them into a focused reference file or study then.

### Seed directions worth collecting

These are invitations, not folders that must exist:

- dense expert interfaces;
- native desktop applications;
- mobile interactions that disappear into gesture/voice;
- excellent sidebars and navigation rails;
- command discovery and expert acceleration;
- information-first technical/product pages;
- typography with unusually strong hierarchy;
- motion that clarifies causality;
- motion that becomes irritating under repetition;
- playful software that keeps hot paths direct;
- game UIs with strong atmosphere;
- physical controls and industrial objects;
- dashboards where normal state stays quiet;
- spatial tools and wayfinding;
- diagrams that explain difficult mechanisms immediately;
- unusual interfaces that violate convention successfully.

## Promotion

A reservoir item can remain a reservoir item forever.

Promote it only when another job appears:

- **study** — recreate or vary the thing to understand how it works;
- **case study** — apply the lesson against a real product/workflow;
- **pattern** — several unrelated cases support the same reusable move;
- **signature** — Leo repeatedly chooses the same direction across different work;
- **shit list** — the useful lesson is a specific failure and its correction.

## Agent behavior

When an agent is asked to add references:

1. prefer a small number of genuinely useful finds over a large inspiration dump;
2. preserve source links and visual evidence where possible;
3. write the exact mechanism worth revisiting;
4. do not synthesize a new principle unless multiple cases earn it;
5. do not reorganize the reservoir simply to make it look tidy.

The reservoir should feel closer to a studio wall, camera roll, or well-annotated bookmarks folder than a design textbook.
